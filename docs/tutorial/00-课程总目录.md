# 从零独立开发“学习空间”

这不是一份让你快速复制代码的说明书，而是一套从“我甚至不知道开发软件是什么”开始的完整课程。最终目标不是让你记住所有语法，而是让你能够独立理解、修改、测试并发布“学习空间”项目。

> [!important] 你不需要先会编程
> 第 01 章从软件、程序和源码的区别讲起。课程会解释每个首次出现的术语、每条命令在哪里运行、正常情况下会看到什么，以及画面不同时如何检查。

> [!note] 教程中的项目路径
> Windows 示例统一使用 `D:\Projects\study-space`。如果你把项目保存在其他位置，请将命令中这段路径换成自己的实际项目目录。

## 这套课程怎么使用

这是一套独立、完整的教程，不需要配合其他项目文档阅读。第一次学习时请从第 01 章开始，按照章节顺序完成讲解、练习和复盘；已经掌握基础后，可以通过本目录直接跳到需要查询的模块。

如果你目前还不清楚终端、源码、前端、后端或数据库是什么，也不用提前补课：这些概念都会在课程中从零解释。

## 最终会学到什么

完成全部课程后，你应该能够：

- 从空文件夹创建一个 React、TypeScript 与 Tauri 应用；
- 理解界面、服务层、Rust 后端和 SQLite 数据库怎样配合；
- 修改首页、专注学习、英语、数学、政治、专业课和资料库；
- 为修改编写测试，利用错误信息定位问题；
- 保护用户数据、密钥和现有未提交代码；
- 构建 Windows 应用与 Android 平板应用；
- 面对没有现成答案的问题，自己阅读文档并完成验证。

## 学习路线

```mermaid
flowchart LR
    A[认识软件与源码] --> B[理解文件和路径]
    B --> C[认识编辑器与终端]
    C --> D[安装开发环境]
    D --> E[安全使用命令行]
    E --> F[用 Git 保护修改]
    F --> G[进入 Web 与编程基础]
    G --> H[React 与 TypeScript]
    H --> I[Tauri、Rust 与 SQLite]
    I --> J[从零实现学习空间]
    J --> K[测试、发布与独立开发]
```

建议严格按箭头方向学习。前六章是在为后面所有内容搭地基；基础阶段走得慢并不丢人，跳过才更容易反复卡住。

## 每次学习怎么安排

一次安排 45～90 分钟即可：

1. 用 5 分钟回忆上次内容，不看答案写下记得的三个概念；
2. 用 15～30 分钟学习一个小节；
3. 用 15～30 分钟亲手输入命令或代码；
4. 用 10 分钟完成必做练习；
5. 用 5 分钟写错误记录和一句自己的总结。

如果一章需要两三次学习才能完成，这完全正常。不要为了勾选“已完成”而跳过练习。

详细方法见：[学习方法与进度表](00-学习方法与进度表.md)。

## 学习状态怎么标记

在章节链接前的复选框之外，再在自己的学习记录中使用四种状态：

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 未开始 | 尚未阅读 | 按推荐顺序开始 |
| 学习中 | 正在阅读或跟做 | 继续完成必做练习 |
| 已完成 | 能脱离答案重复操作 | 一周后复习一次 |
| 需复习 | 忘记概念或无法独立完成 | 重做练习，不必从头抄全文 |
