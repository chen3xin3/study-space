# 中英文开发术语表

这份表用于查词，不用于替代章节学习。英文错误信息常常不会翻译这些词，所以建议同时记住中英文和一个真实例子。

## 软件与运行

| 中文 / English | 用普通话解释 | “学习空间”中的例子 | 容易混淆 |
| --- | --- | --- | --- |
| 应用程序 / application | 为用户完成一组任务的软件 | 安装后可以打开的“学习空间” | 不等于源码文件夹 |
| 可执行文件 / executable | 操作系统可以直接启动的程序文件 | Windows 构建产生的 `.exe` | `.tsx`、`.rs` 不是可执行文件 |
| 源代码 / source code | 开发者写给工具读取和转换的文本 | `src/app/App.tsx`、`src-tauri/src/lib.rs` | 不等于安装包 |
| 编译 / compile | 把一种源码检查并转换成另一种可运行形式 | Rust 编译为本机程序 | 不等于打开编辑器 |
| 构建 / build | 汇集编译、打包、复制资源等步骤，产生发布结果 | `npm run build` 或 Tauri build | 构建成功不等于已经发布 |
| 运行时 / runtime | 程序正在运行时依赖的环境与行为 | 浏览器 JavaScript 环境、Tauri 桌面环境 | 不等于开发工具安装阶段 |
| 安装包 / installer | 把应用放到系统正确位置并注册配置的文件 | Windows NSIS 安装程序 | 不等于便携版程序 |
| 进程 / process | 一个正在运行的程序实例 | 打开“学习空间”后系统中的进程 | 文件放在磁盘上时不是进程 |
| 端口 / port | 一台电脑上区分网络服务的数字入口 | Vite 开发服务使用 `1420` | 不等于网页地址本身 |
| 本机地址 / localhost | 指向当前这台电脑的网络名称 | `http://localhost:1420` | 平板上的 localhost 指平板自己，不是电脑 |
| APK / Android Package Kit | Android 应用安装包格式 | 平板上安装的“学习空间”文件 | 不是 Android 源码 |

## 文件与工具

| 中文 / English | 用普通话解释 | “学习空间”中的例子 | 容易混淆 |
| --- | --- | --- | --- |
| 文件扩展名 / file extension | 文件名末尾表示常见格式的部分 | `.tsx`、`.css`、`.json` | 改名字不能真正转换格式 |
| 路径 / path | 表示文件或文件夹位置的文字 | `D:\Desktop\app` | 路径不一定是一条命令 |
| 绝对路径 / absolute path | 从磁盘或根位置开始的完整地址 | `D:\Desktop\app\package.json` | 与当前目录无关 |
| 相对路径 / relative path | 从当前目录或当前文件出发的位置 | `src/app/App.tsx` | 起点不同，含义也不同 |
| 环境变量 / environment variable | 系统或进程保存的命名配置 | `PATH` 决定到哪里找 `node` | 不等于项目里的普通变量 |
| 编辑器 / editor | 用于查看和修改文本文件的工具 | VS Code | 不等于编译器或应用本身 |
| IDE / Integrated Development Environment | 集成编辑、调试、构建等功能的开发环境 | Android Studio | VS Code 可通过扩展具备部分 IDE 能力 |
| 终端 / terminal | 显示命令输入与输出的界面 | VS Code 底部终端面板 | PowerShell 是在终端里运行的 shell |
| 命令解释器 / shell | 读取并执行命令的程序 | PowerShell | 不等于 Windows 的整个界面 |
| 命令 / command | 请求工具执行动作的名称 | `git status` 中的 `git` | 后面的选项和路径属于参数 |
| 参数 / argument | 交给命令的额外信息 | `git diff --cached` 中的 `diff`、`--cached` | 不等于函数参数，但思想类似 |
| 调试 / debug | 用证据逐步定位程序为何不符合预期 | 查看 Console 错误和变量值 | 不等于随意试改代码 |
| 调用栈 / stack trace | 错误发生前经过的函数调用路线 | Rust 或 JavaScript 报错后的文件与行号 | 最后一行不一定是根因 |

## Web 与前端

| 中文 / English | 用普通话解释 | “学习空间”中的例子 | 容易混淆 |
| --- | --- | --- | --- |
| 前端 / frontend | 用户直接看到和操作的界面层 | `src` 下的 React 页面 | 不代表所有业务逻辑都应放前端 |
| 后端 / backend | 负责数据、文件、权限或远程服务的后台逻辑 | `src-tauri/src` 的 Rust 代码 | 本地应用的后端也可以不联网 |
| 接口 / API | 两部分软件约定好的调用方式 | 前端调用 Tauri command | API 不一定是网络网址 |
| 依赖 / dependency | 项目使用的外部库或工具 | React、Tauri API、Lucide 图标 | 不应直接编辑 `node_modules` 中的依赖源码 |
| 包管理器 / package manager | 安装和记录依赖的工具 | npm、Cargo | 不等于应用商店 |
| Node.js | 在浏览器外运行 JavaScript 的环境 | 运行 Vite、测试和教程检查器 | 不是 React，也不是浏览器 |
| npm / Node Package Manager | Node.js 常用的包管理器与脚本入口 | `npm install`、`npm run build` | `npm` 不是某一个依赖包 |
| Vite | 前端开发服务器和构建工具 | 启动浏览器预览、生成 `dist` | 不负责 SQLite 数据库 |
| React | 用组件和状态构建用户界面的库 | 首页、导航和表单组件 | React 不是完整桌面外壳 |
| TypeScript | 为 JavaScript 增加静态类型检查的语言 | `.ts`、`.tsx` 文件 | 最终浏览器执行的是转换后的 JavaScript |
| 组件 / component | 可组合、可复用的界面单位 | 待办卡片、导航项 | 不一定对应一个完整页面 |
| 状态 / state | 运行期间会变化并影响界面的数据 | 计时是否暂停、任务列表 | 不等于永久数据库记录 |
| 路由 / route | 地址与页面之间的映射 | `/english` 显示英语页面 | 不等于文件系统路径 |

## Tauri、Rust 与数据

| 中文 / English | 用普通话解释 | “学习空间”中的例子 | 容易混淆 |
| --- | --- | --- | --- |
| Tauri | 用 Web 界面配合 Rust 构建桌面和移动应用的框架 | Windows/Android 外壳与 command 调用 | 不等于 React，也不自动提供数据库 |
| Rust | 强调安全和性能的系统编程语言 | 本地数据、附件和诊断命令 | Rust 文件扩展名是 `.rs` |
| Cargo | Rust 的包管理与构建工具 | `cargo test`、`Cargo.toml` | 类似 npm 的角色，但管理 Rust 项目 |
| 数据库 / database | 按结构长期保存和查询数据的系统 | 保存学习任务、资料和统计 | 不等于某个界面表格 |
| SQLite | 把关系数据库保存在本地文件中的数据库引擎 | 应用设备内的本地数据 | 不是云同步服务 |
| 表 / table | 同类数据按字段组织的集合 | 任务表、学习项目表 | 不等于屏幕上的 HTML 表格 |
| 行 / row | 表里的一条记录 | 一条今日任务 | 不等于代码的一行 |
| 列 / column | 记录中固定含义的字段 | 标题、完成时间 | 不等于电子表格中的任意单元格 |
| 主键 / primary key | 唯一识别一条记录的字段 | 某条任务的 ID | 标题通常不能当可靠主键 |
| 迁移 / migration | 按版本安全改变数据库结构的步骤 | 新版本增加字段或表 | 不等于复制数据库文件 |

## 质量与协作

| 中文 / English | 用普通话解释 | “学习空间”中的例子 | 容易混淆 |
| --- | --- | --- | --- |
| 仓库 / repository | 由 Git 管理历史的项目目录 | `D:\Desktop\app` | 不等于远程 GitHub 网站 |
| 工作区 / working tree | 当前磁盘上可编辑的项目文件状态 | 尚未提交的页面修改 | 不等于 Git 提交历史 |
| 暂存区 / staging area | 选择下一次提交包含哪些变化的区域 | 只暂存教程文件 | 不等于已经提交 |
| 提交 / commit | 带说明的本地历史检查点 | `docs: add course entrance` | 不等于上传到远程 |
| 分支 / branch | 指向一条开发历史线的名称 | `codex/android-060` | 不等于复制一份普通文件夹 |
| 测试 / test | 自动运行并判断行为是否符合约定的代码 | Vitest、Rust tests | 测试通过不证明所有人工场景都正确 |
| 断言 / assertion | 测试中对结果提出的明确要求 | 期望页面出现“学习日历” | 不等于普通日志输出 |
| 版本控制 / version control | 记录、比较和组织文件变化的方法 | Git | 不是自动备份所有未保存数据 |
| API Key | 服务识别调用者的秘密凭证 | AI 服务密钥 | 不能写进源码或截图公开 |

## 查词方法

1. 先找错误信息里的核心英文词；
2. 在本表找到普通话解释；
3. 回到所在章节看完整上下文；
4. 用自己的话造一个项目例子；
5. 仍然不懂时，再查对应工具的官方文档。
