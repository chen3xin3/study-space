# 第 35 章：实现专注计时

## 本章目标

实现开始、暂停、继续、休息、中断记录、结束复盘和重启恢复；保证休息时间永远不进入有效学习时间。

## 开始前需要会什么

理解时间戳、纯函数、可序列化对象和 React Effect 清理。

## 新术语表

| 术语 | 含义 |
|---|---|
| State machine | 状态只能沿允许路线变化 |
| Timestamp | 某个真实时刻的数字 |
| Accumulated work | 已结算的有效学习时长 |
| Tick | 仅用于刷新显示的周期通知 |
| Serializable | 能保存为 JSON 并恢复 |

## 先建立直觉

setInterval 不是钟，它只是提醒页面“该重画了”。真实时间来自 Date.now。暂停或关闭页面后，下一次用时间戳相减才能恢复；休息状态没有 activeSince，因此不会累加。

## 图解

~~~mermaid
stateDiagram-v2
  [*] --> running: 开始
  running --> paused: 暂停并结算
  paused --> running: 继续并记录新起点
  running --> break: 开始休息并结算
  break --> running: 继续
  running --> finished: 结束复盘
  paused --> finished: 结束复盘
~~~

## 跟我一步一步做

1. 在 [focus-clock.test.ts](../labs/study-space-app/src/domain/focus-clock.test.ts) 用固定毫秒测试，不等待真实时间。
2. 在 [focus-clock.ts](../labs/study-space-app/src/domain/focus-clock.ts) 保存 status、accumulatedWorkMs、activeSince、中断和复盘。
3. elapsedWorkMs 只在 running 且 activeSince 非空时增加 now-activeSince。
4. pause 和 startBreak 先结算当前工作段，再把 activeSince 清空。
5. resume 从当前真实时刻建立新工作段；休息的十分钟不会出现在公式里。
6. JSON 序列化再解析后运行同一计算，证明页面重启可恢复。
7. 在 [FocusPage.tsx](../labs/study-space-app/src/pages/FocusPage.tsx) 让定时器只更新 now，绝不直接给学习秒数加一。
8. 用主计时舞台、任务轨道和底部工具栏形成有辨识度但清晰的界面。

## 完整示例

~~~ts
const started = startSession("整理阅读错题", 1_000);
const resting = startBreak(started, 61_000);
elapsedWorkMs(resting, 661_000); // 仍是 60_000
const resumed = resumeSession(resting, 700_000);
elapsedWorkMs(resumed, 760_000); // 120_000
~~~

## 逐段解释

accumulatedWorkMs 保存已经结束的工作段；activeSince 只保存当前工作段起点。这比不断加一更能抵抗休眠、后台节流和页面切换。状态转换函数拒绝无意义路线，例如 finished 不能 resume。真实项目还要把状态持久化到 Rust 与 SQLite。

## 运行并观察

启动一轮，暂停几秒再继续，开始休息并等待，确认数字在休息时不增加；记录中断，最后结束并复盘。运行测试，重点看“does not count paused or break time”。

## 常见错误与修复

- 每秒 state+1：后台节流会丢时间，改用时间戳推导。
- 休息仍保留 activeSince：会把休息误算成学习。
- 重启只保存显示字符串：无法继续计算，应保存结构化状态。
- Effect 未 clearInterval：重复定时器造成多次刷新。
- 结束按钮只关弹窗：必须结算最后工作段并保存复盘。

## 必做练习

画出四个状态与按钮；增加非法转换测试；证明 20 分钟工作+10 分钟休息+5 分钟工作等于 25 分钟有效学习；解释页面切后台为何不能相信 tick 次数。

## 选做挑战

加入多轮目标、长休息规则和环境音选择。业务计时与声音播放必须分开，声音失败不能破坏专注记录。

## 答案与思路

有效时长只合并 running 区间；break 与 paused 都没有活动起点。非法转换应返回原状态或领域错误，项目内要统一选择。tick 可能被浏览器暂停，真实时间戳不会依赖回调次数。
